# Ej10 · Tu Android Studio por dentro 🤖

**Apartado 6 · Instalación de Android Studio** · ⏱️ 25 min

> 🎯 Comprobar que tu instalación está completa y saber **dónde** se ven y se gestionan sus piezas: versión del IDE, SDK de Android, JDK embebido y emuladores.

## Pasos

**PASO 1.** **Help → About** (en macOS, *Android Studio → About*): anota la **versión** y el nombre en clave (por ejemplo *Narwhal*).

**PASO 2.** **Tools → SDK Manager** → pestaña **SDK Platforms**: anota qué versiones de Android tienes instaladas. Pestaña **SDK Tools**: comprueba que tienes *Android SDK Build-Tools*, *Android Emulator* y *Android SDK Platform-Tools*.

**PASO 3.** En la misma ventana, copia la **ruta del SDK** (*Android SDK Location*).

**PASO 4.** **File → Settings → Build, Execution, Deployment → Build Tools → Gradle**: anota qué **JDK** usa Gradle (*Gradle JDK*).

**PASO 5.** **Tools → Device Manager**: anota tus emuladores (o crea uno, si no tienes).

**PASO 6.** Rellena [`RESPUESTAS.md`](RESPUESTAS.md).
