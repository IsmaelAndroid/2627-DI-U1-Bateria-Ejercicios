# Ej06 · Componentes reutilizables 🟣

**Apartado 3 · Modelo basado en componentes** · ⏱️ 40 min

> 🎯 Un componente se define **una vez** y se **reutiliza** en cualquier pantalla. Vas a construir una mini librería de **funciones** que devuelven trozos de «interfaz» (listas de líneas de texto) y que se **combinan** unas dentro de otras, igual que los composables `Column`, `Row`, `Card`, `Text` y `Button`.

## Pasos

Completa [`Tarjetas.kt`](Tarjetas.kt) y ejecútalo:

```bash
./ejecutar.sh ejercicios/ej06-componentes-reutilizables/Tarjetas.kt
```

## ✅ Comprueba

```text
+---------------------+
| Ana                 |
+---------------------+
| 2º DAM              |
| [ Ver ]  [ Editar ] |
+---------------------+
+---------------------+
| Luis                |
+---------------------+
| 1º DAM              |
| [ Ver ]  [ Editar ] |
+---------------------+
```
