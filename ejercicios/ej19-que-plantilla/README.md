# Ej19 · ¿Qué plantilla elijo? 🟣

**Apartado 8.5 · Tipos de proyecto nuevos** · ⏱️ 25 min

> 🎯 Saber qué **plantilla de proyecto** de Android Studio elegir en cada situación.

## Pasos

**PASO 1.** Lee el `enum` `Plantilla` de [`Plantillas.kt`](Plantillas.kt): cada valor lleva lo que genera.

**PASO 2.** En el mapa `respuestas`, todos los casos tienen ahora `Plantilla.EMPTY_ACTIVITY`. Cambia cada uno por la plantilla correcta. Hay **8 casos** y cada uno usa una plantilla **distinta**.

**PASO 3.** Ejecuta:

```bash
./ejecutar.sh ejercicios/ej19-que-plantilla/Plantillas.kt
```

## ✅ Comprueba

- Salen 8 líneas, una por caso.
- La última dice `Plantillas distintas usadas: 8 de 9`. Si sale menos, has repetido alguna.
